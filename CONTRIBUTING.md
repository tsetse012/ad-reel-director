# Contributing

This is a one-person project maintained between app releases. Issues and PRs are welcome; a reply may take a while.

What helps most:

- **A prompt rule that fixed a real defect**, with the before/after (a frame strip is enough). Rules without a failure behind them are not added.
- **Provider notes** — a model id, a parameter limit, a price — with the date you observed it. Gateways change weekly.
- **Another route** (fal, Higgsfield, Dreamina) as a separate script that keeps the same inputs/outputs as `render_seedance.py`.

What is out of scope: automatic publishing, BGM generation, upscaling. They are easy to bolt on and hard to keep working.

Do not commit renders, stills you do not own, API keys, or `.env`. Do not add reference images of real people.
