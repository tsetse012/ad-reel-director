# 줍냥이 광고 강아지 편 릴스 본문 (2026-09-07)

> 톤·금지선은 고양이 편과 동일(`marketing/PROMO_COPY.md`): 1인 개발자 진심, 위치/지도 ❌, 확률 ❌, "완전 무료" 단정 ❌, 리뷰 유도 ❌.
> 고양이 편이 "길에서 만난 아이"였다면 이번엔 "매일 보는 우리 집 아이도 카드가 된다"가 포인트.

## A. 메인 (붙여넣기용)

```
매일 보는 우리 집 미남도, 오늘은 카드로 남겼어요.

길냥이만 되는 게 아니에요.
우리 집 댕댕이 사진 한 장도 그림책 카드가 되고,
이름이랑 성격, 한 줄 이야기가 붙어서 도감에 들어가요.

고양이랑 강아지 좋아하는 마음 하나로 혼자 만든 앱이에요.
· 카드는 내 폰 안에만 저장
· 로그인 없이, 무료로 시작

아침마다 놀아달라고 보채는 아이가 있다면, 오늘 한 장 남겨보세요.
App Store에 ‘줍냥이’ 🐾

#줍냥이 #댕댕이 #멍스타그램 #말티즈 #강아지 #반려견 #견스타그램 #강아지그램 #길냥이 #앱추천
```

## B. 짧은 버전

```
우리 집 미남, 오늘 도감 등록 완료 🐾

댕댕이 사진 한 장이 그림책 카드가 되는 앱. 혼자 만들었어요.
로그인 없이 무료로 시작할 수 있어요.

App Store에 ‘줍냥이’

#줍냥이 #댕댕이 #멍스타그램 #말티즈 #강아지 #반려견
```

## 메모

- 영상 대사 ③ "우리 집 미남도 등록 완료"를 본문 첫 줄이 받는다.
- 커버 추천: 1초(무릎에 앞발 올린 컷) 또는 20초(턱 핥는 컷). 엔드카드는 커버로 쓰지 않는다.
- 고양이 편과 같은 날 올리지 말고 며칠 간격(두 편이 서로 커버 노출을 갉아먹지 않게).
