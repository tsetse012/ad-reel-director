# ad-reel-director

앱 광고 30초를 **영상 한 번 렌더**로 만드는 방법입니다. 스틸로 정체성을 잠그고, 한 장짜리 무브보드로 이야기를 잠근 뒤,
Seedance 2.5가 목소리·효과음까지 포함해 30초를 한 번에 그립니다. 엔드카드와 BGM은 ffmpeg로 붙입니다.

[English README](README.md) · `SKILL.md`는 Claude Code(또는 다른 코딩 에이전트)용 매뉴얼이고, 사람은 이 페이지만 보면 됩니다.

## 렌더 경로 둘 — 둘 다 씁니다

- **i2v(2점 앵커)**: 시작·끝 프레임을 픽셀로 고정, 중간은 프롬프트. 엔딩 구도·밝기가 정확해야 할 때.
- **r2v(시작 프레임 + 시트 패널)**: `[kf1, 얼굴, 표정, 자세, 방 와이드, 방 역앵글, 방 로우]`. 폰 화면이 깨끗해야 하거나 얼굴이 상품일 때.
- **r2v에 씬 키프레임 5장을 넣지 마세요.** 스틸마다 방이 조금씩 달라서 컷마다 배경이 뭉개집니다. 이 규칙이 생긴 사고가 `examples/nunchi`의 A/B입니다.

## 퀄리티를 실제로 바꾼 것

1. 슬라이드쇼 대신 **원샷 렌더** 2. **3테이크 2컷**(컷마다 배경이 다시 그려짐) 3. **정지 금지 문단**(없으면 15초·27초에서 화면을 멈추고 줌함)
4. **시트를 낱장으로 잘라** 넣기 5. r2v 레퍼는 **씬이 아니라 시트** 6. **표정은 긍정문으로** 7. **렌더에 BGM 금지**(저작권 필터) 8. **초당 움직임 수치**로 QA

## 비용(Atlas Cloud, 2026-09 기준, 실호출로 재확인)

스틸 한 장 약 $0.17, 스틸 13장 약 $2~3, 30초 렌더 약 $4(7~15분), 리테이크 1회 포함 한 편 약 $10~15.

## 한계

폰 화면에 작은 카메라 UI가 자꾸 생깁니다(글자 0이 필요하면 그 3초는 실제 화면 합성). i2v는 마지막 1초가 멈추기 쉽고 r2v는 엔딩이 근사치입니다.
레퍼런스 이미지는 각 변 300px 이상. QA 스트립으로는 소리를 못 들으니 게시 전에 대사 3줄과 음악 유무를 직접 확인하세요.
